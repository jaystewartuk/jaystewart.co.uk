Work

Three products since March 2026.

Each one started from what users actually said or did, and each was built largely with coding agents, with every change checked before it shipped.

SpiralClass

Live · real payments

Scheduling, payments and video for independent teachers. Built and run solo; in production with a teacher and her eight students.

  • Stripe Connect direct charges on the teacher's own account, so the platform never holds the money. Wise as a second rail, reconciled through its API.
  • About 870 test files and one definition of green, run the same way locally and in CI, including real-database integration tests and a migration drift check.
  • Nearly 150 decision records, several of them reversing an earlier call and saying why.
  • TypeScript
  • Next.js
  • Postgres
  • Prisma
  • Stripe Connect
  • Wise
  • LiveKit
  • Inngest

WantToJoin

Pilot · one hostel

A page per hostel for tonight's outings and who's going. Before writing code I read 2,800 messages from a hostel's guest WhatsApp group. They showed that the hosts, not the guests, were the people to build for.

  • From research to a live pilot at that hostel in three days.
  • An AI post writer drafts every post in English and Spanish, checked in code. All 50 eval drafts pass, at about $0.0003 a post.
  • Pilot results, good or bad, published after it ends on 14 October.
  • Cloudflare Workers
  • D1
  • PostHog
  • Claude Haiku

Beckon

Live · October 2026

A remote inbox for terminal agents. Your phone tells you when Claude Code or a build is waiting, and you approve or deny from the lock screen.

  • End-to-end encrypted. The helper only types a response signed by a device you paired with a six-word safety code.
  • A Go helper, a Next.js and WebSocket service, and an installable web app with push notifications.
  • Runs on one hardened VM with monitoring, a dead man's switch and tested, encrypted offsite backups. No outside users yet.
  • Go
  • TypeScript
  • Next.js
  • Postgres
  • WebSockets
  • Web Push
